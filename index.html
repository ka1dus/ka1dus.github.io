  3. 03

    Patrol-robot operator assistant ↗

    An on-premise RAG assistant for the operators of a rideable patrol robot. It answers only from the user guide, checks its own citations, and hands off to the hotline instead of guessing.

    2026BotmindLocal LLM · Hybrid retrieval · FastAPI
    I stopped a task by mistake, can I get it back?
    No. A stopped task can’t be resumed, only a paused one. Send the task again from the Tasks list. high confidence · guide p.13/14
    What torque do the wheel bolts take?
    That isn’t covered in the user guide. Calling the hotline…escalated · out of scope
  4. 04

    WhatsApp lead-qualification agent

    An LLM agent for JimaiConsulting clients that answers inbound leads on WhatsApp, asks the qualifying questions a salesperson would, then checks free slots and books the appointment itself through tool calls to Google Calendar.

    Built for production rather than a demo: triggers are idempotent, so a repeated webhook doesn’t book twice, and failed calls are retried instead of losing the lead.
